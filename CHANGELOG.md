# Changelog

## [0.1.0] — initial public alpha (GitHub source distribution; not PyPI)

- Strict JSON plan validation, typed immutable models and explicit error paths.
- Deterministic summary and week-expanded, formula-safe CSV export.
- Python CLI with input size protection and safe existing-file refusal.
- Automated tests, CI configuration and contributor documentation.

- Public quickstart, API reference, maintainer guide, reviewed release notes and two scoped contributor issues.
- Verified CI: Ruff, 31 unit tests, compilation and CLI smoke tests on Python 3.11, 3.12 and 3.13.
