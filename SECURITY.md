# Security Policy

This is an early public-source prototype (`0.1.x`). No security support SLA is promised.

Report vulnerabilities privately using GitHub's **Report a vulnerability** feature
if private vulnerability reporting is enabled. If the feature is unavailable,
do not publish exploit details in a public issue; contact the maintainer privately.
Do not disclose exploit details, client data or credentials in public issues.

Expected threat model: untrusted JSON files, CSV formula injection and unexpected
filesystem paths. No execution of user code or network access is intended.
Do not put identifiable client or health information into example files.
